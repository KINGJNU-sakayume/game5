# 🌟 리듬 별나라 (Rhythm Starland)

『리듬 천국』 시리즈(리듬 천국 미라클 스타)의 플레이 방식을 최대한 그대로 살린 **모바일 리듬 게임**입니다.
아이폰 15 Pro 화면(393×852pt, 1179×2556px)에 **꽉 차도록** 만든 웹 앱(PWA)이며,
GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포까지 자동으로 해 줍니다.

> 모든 그림은 Canvas 코드로, 모든 음악/효과음은 Web Audio 합성으로 직접 만든 **오리지널**입니다.
> 닌텐도의 캐릭터·음원·이미지는 사용하지 않았습니다. (게임 규칙과 흐름만 오마주)

## 🎮 게임 구성

리듬 천국처럼 **게임 4개 + 리믹스 1개**가 한 세트(총 3세트, 15스테이지)이고, 앞의 게임을 "평범" 이상으로 깨면 다음 게임이 열립니다.

| 세트 | 게임 | 조작 | 규칙 (원작의 비슷한 게임) |
| --- | --- | --- | --- |
| 1 | 🍅 촙촙 셰프 | 탭 | 날아온 재료를 한 박자 뒤에 썰기. 떡은 1.5박, 수박은 2박 뒤 (가라테 계열) |
| 1 | 🐦 짹짹 트리오 | 탭 | 앞의 두 마리와 같은 간격으로 짹! (박수 트리오 계열) |
| 1 | 🎈 풍선 공장 | 누르고 있다가 떼기 | 풍선 크기별로 1·2·3박 뒤에 손 떼기 (로봇 충전 계열) |
| 1 | 🥷 닌자 수련 | 플릭(쓱 밀기) | 튀어 오른 통나무를 박자에 맞춰 베기 (사무라이 계열) |
| 1 | 🌈 리믹스 1 | 모두 | 위 4개 게임이 새 노래에 맞춰 번갈아 등장 |
| 2 | 🐧 펭귄 행진 | 탭 | 정박 행진 → 호루라기 신호에 엇박자로 전환 (행진 계열) |
| 2 | 🐰 달토끼 배드민턴 | 탭 | 랠리, 높은 공(2박), 스매시(0.5박) (에어 랠리 계열) |
| 2 | 🐸 개구리 합창단 | 탭 | 대장이 부른 리듬을 다음 마디에 그대로 (따라 부르기 계열) |
| 2 | 🧚 요정 왈츠 | 탭 | 3/4박자, 요정이 앞을 지날 때 탭 (마법사 왈츠 계열) |
| 2 | 🌈 리믹스 2 | 모두 | 세트 2 게임 메들리 |
| 3 | ⭐ 응원단 | 탭 + 플릭 | 아이돌 노래 뒤에 짝짝, "다 같이~" 뒤에 위로 쓱 야호! (팬클럽 계열) |
| 3 | 🥕 쏙쏙 수염 뽑기 | 탭 / 플릭 | 한 마디 동안 돋은 수염을 다음 마디에 같은 리듬으로 (짧은 수염=탭, 긴 수염=플릭) (핀셋 계열) |
| 3 | 🐻 냠냠 곰돌이 | 좌/우 탭 | 왼쪽 도넛은 왼쪽, 오른쪽 케이크는 오른쪽, 양쪽이면 두 손가락 |
| 3 | 🎆 불꽃놀이 | 탭 | "도·미·솔" 카운트다운과 같은 간격으로 발사 (빠르게/느리게/셋잇단) |
| 3 | 🌈 리믹스 3 | 모두 | 세트 3 + 셰프·닌자 특별 출연 피날레 → 엔딩 스태프 롤 |

원작과 같은 요소
- **연습 → 실전** 흐름 (처음엔 연습부터, 성공 횟수를 채우면 다음 단계)
- 플레이 중 점수 표시 없음, **소리와 그림으로만** 성공/실패를 느끼기
- 결과 화면의 **리듬 판정 코멘트**, 등급 도장 **「다시 한 번 / 평범 / 하이레벨」**, 에필로그 그림
- 하이레벨 **메달**, 실수 없이 깨는 **퍼펙트 도전**
- 판정: Just ±65ms, Barely ±125ms (80점 이상 하이레벨, 60점 이상 평범)

## 📱 아이폰에서 전체 화면으로 플레이하기

1. 배포된 주소를 **Safari**로 엽니다. (이 저장소: `https://kingjnu-sakayume.github.io/game5/`)
2. **공유 버튼 → "홈 화면에 추가"**
3. 홈 화면 아이콘으로 실행하면 주소창 없이 **화면 전체(다이나믹 아일랜드·홈 인디케이터 영역까지)**를 채웁니다.
   - `viewport-fit=cover` + `black-translucent` 상태 막대 + 세이프 에어리어 대응
   - 아이폰 15 Pro 전용 1179×2556 시작 화면(스플래시) 포함
   - 무음 모드여도 소리가 나도록 `navigator.audioSession = 'playback'` 사용
   - 한 번 열면 오프라인에서도 플레이 가능 (서비스 워커)

블루투스 이어폰처럼 소리가 늦게 들리면 **설정 → 타이밍 보정**으로 맞춰 주세요.

## 🚀 GitHub Actions / GitHub Pages

`.github/workflows/ci.yml`

| 작업 | 내용 |
| --- | --- |
| `test` | 타입 검사, 단위 테스트(15개 스테이지 모두 자동 플레이 100점·모든 장면 그리기 검증), 빌드, 결과물 업로드 |
| `e2e` | Playwright(Chromium)로 **iPhone 15 Pro(393×852 @3x)** 화면에서 캔버스가 1179×2556으로 꽉 차는지, 메뉴·게임·결과 화면까지 실제로 플레이되는지 검사 (스크린샷 아티팩트) |
| `e2e-webkit` | 같은 검사를 **WebKit(Safari 엔진)** + 아이폰 15 Pro 프로필로 한 번 더 |
| `deploy` | 기본 브랜치에 push 되면 GitHub Pages로 자동 배포 (Pages가 아직 꺼져 있으면 설정 방법을 경고로 안내하고 건너뜀) |

**처음 한 번만** 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿔 주세요.
그 뒤 Actions 탭에서 워크플로를 다시 실행(Re-run)하면 배포됩니다.

## 🛠 개발

```bash
npm install
npm run dev        # 개발 서버 (같은 Wi-Fi의 아이폰에서도 접속 가능)
npm test           # 단위 테스트
npm run build      # dist/ 에 배포용 빌드
npm run test:e2e   # E2E 테스트 (npx playwright install chromium 필요)
npm run assets     # 아이콘/시작 화면 PNG 다시 만들기
```

디버그용 주소 파라미터: `?auto=1` (자동 플레이), `?rate=2` (배속)
브라우저 콘솔: `__rs.start('chef', { autoplay: true })`, `__rs.preview('ninja', 12.3)`

PC에서는 `Space` = 탭(누르고 있으면 홀드), `F`/`J` = 왼쪽/오른쪽 탭, `K/D/방향키` = 플릭, `Esc` = 일시정지.
